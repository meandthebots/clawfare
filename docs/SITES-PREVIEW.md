# Read-only ChatGPT Sites preview

Clawfare can export the **actual existing web UI** and bundled Florida sample into
one HTML file. It does not need credentials, Kotlin/JS, D1 or the live Ktor server.

## Build

```bash
bash scripts/build-sites-preview.sh build/sites/clawfare-sample.html
```

The script uses a disposable SQLite database, clears provider credentials and
runs only `fare load-sample` and `report html`. The output is self-contained:
it has an embedded sample snapshot, browser-side filters, itinerary details,
matrix, vendors and exports. It is *not* live airfare or real-time availability.

The preview build also writes `clawfare-sample.json`, the exact serialized
`ResultSet` returned by the existing JVM `/api/sample` endpoint. It is built
directly from the **bundled public fixture**, never from user searches or
arbitrary provider data. Import this JSON only through a trusted, authenticated
administrative path into D1 `investigation_snapshots` for the intended viewer.
The hosted API must not allow anonymous users to write snapshots or choose
arbitrary owners.

The equivalent standalone CLI command is:

```sh
./gradlew run --args="report sample-json --out build/sites/clawfare-sample.json"
```

## GitHub Actions

Run **Build read-only Sites preview** (or open a PR changing its inputs).
Download the `clawfare-sites-sample` workflow artifact. It contains the self-contained HTML page and the matching
public sample ResultSet JSON. The workflow uploads no database, keys or other private data.

## Publishing

Open ChatGPT Work with @Sites on web/desktop. Attach the HTML artifact and ask it
to create a private read-only site preserving the markup, scripts, filters and
sample content. Review the private preview before publishing. Hosted Sites
provisioning and production URL creation take place in Sites, not in this repo.

**Do not enable live search** by inserting provider keys into the HTML or
bypassing the server's estimate/confirmation checks. Complete the Kotlin/JS D1
backend in issue #42 before supporting paid search.

The preview can remain a GitHub artifact even if Sites cannot accept the
unchanged HTML directly. The versioned source of truth is the repository and
the bundle generated by the script.
